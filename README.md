# 🏗️ نظام محاسبة المقاولات المتكامل

منظومة محاسبية متكاملة مصممة خصيصًا لشركات المقاولات والمقاولين — بالعربية بالكامل، بواجهة عصرية داكنة، وتقارير PDF فخمة معتمدة رسميًا.

📥 **التحميل (نسخة واحدة نظيفة — البرنامج EXE بدون أي نافذة أوامر):**
https://github.com/ahmedboney/construction-accounting-system/releases

## ✨ أبرز المميزات

### 🌙 الواجهة
- النظام **كله دارك مود** (وضع ليلي فاخر كحلي وذهبي) — بدون أي وضع فاتح أو أزرار تبديل.

### 📋 إدارة المشاريع والعقود
- سجل كامل للمشاريع (سكني/تجاري/بنية تحتية) مع حالاتها وتواريخها.
- عقد لكل مشروع: قيمة العقد، نسبة العقد المقدم، نسبة الضمان (الاحتجاز).
- بنود الكميات (BoQ) والميزانية التقديرية لكل مشروع.
- تحذير تلقائي عند تجاوز الأعمال المنفذة سقف العقد.

### 📋 المستخلصات والتحصيل
- مستخلصات بأرقام تلقائية، محجوز الضمان، الصافي المستحق، والتحصيل الفعلي.
- تحرير/إعادة حجز الضمانات بترحيل محاسبي تلقائي.
- **فاتورة ضريبية رسمية PDF** لكل دفعة عميل (ضريبة قيمة مضافة).
- تتبع الشيكات والتحويلات وطريقة كل دفعة.

### 💸 التكاليف والالتزامات
- تكاليف المشاريع (مواد/عمالة/معدات/مقاولي باطن/أخرى).
- مدفوعات الموردين ومقاولي الباطن.
- **فواتير موردين** مع **تاريخ استحقاق** وتنبيهات فورية باللوحة.
- **العهد والأمانات**: صرف وسداد مع رصيد متبقي لكل مسؤول.

### 👷 الرواتب والإهلاك والمخازن
- **مسير رواتب شهري** تلقائي للعمالة، صرف بترحيل محاسبي.
- **إهلاك المعدات** (شهري متسق مع الجانب المحاسبي).
- مخازن: إدخال/صرف مواد، حد أدنى للمخزون وتنبيه نفاد.

### 📚 المحاسبة الكاملة
- دليل حسابات + شجرة حسابات + رصيد افتتاحي.
- قيود يومية (يدوية + استيراد Excel + ترحيل تلقائي لكل العمليات).
- أستاذ عام، ميزان مراجعة، قائمة دخل، مركز مالي، تدفقات نقدية.
- **تقرير أرباح شهري** لكل الشهور.
- **تنبيهات ذكية** على لوحة التحكم.

### 📄 تقارير PDF فخمة (14+ تقرير)
- ترويسة كحلية وذهبية + شعار + خط Noto Sans Arabic (تغطية كاملة لكل الحروف والأرقام العربية والرموز — بدون أي مربعات) + ترقيم صفحات + توقيعات رسمية.
- الأرباح الشهرية، دليل الحسابات، اليومية، الأستاذ، الميزان، القوائم المالية، كشف كل مشروع، مستخلص، عهودات.

### 💾 النسخ الاحتياطي
- **نسخة يومية تلقائية** + **نسخة شهرية تلقائية** (الاحتفاظ بآخر نسخ).
- زر نسخ يدوي + تنزيل + **استعادة** + حذف نسخ قديمة.
- زر **استعادة من ملف** (رفع نسخة `.db` مباشرة والتأكد قبل الاستعادة).

### 🔑 استعادة كلمة المرور
- **نسيت كلمة المرور؟** رابط في صفحة الدخول: اسم المستخدم + إجابة سؤال الأمان ثم كلمة جديدة.
- المدير يضبط سؤال الأمان لكل مستخدم (من صفحة المستخدمين / عند الإنشاء).

### 🔐 الصلاحيات
- ثلاث صلاحيات: **مدير** (كل شيء) / **محاسب** (إضافة وتعديل وحذف دون الإعدادات) / **مشاهد** (عرض فقط).
- سجل عمليات (Audit) لكل فعل.

## 🚀 التشغيل على جهازك

1. ثبّت **Python 3.10+** (فعّل خيار Add to PATH).
2. شغّل: `pip install -r requirements.txt`
3. شغّل: `double-click على تشغيل النظام.bat` أو من الطرفية: `python app.py`
4. افتح `http://127.0.0.1:5010`

> عند التشغيل من EXE يفتح المتصفح تلقائيًا **دون أي نافذة أوامر** (زر التشغيل الصامت `تشغيل النظام.vbs` يفتح البرنامج ويخفي أي نافذة CMD).
> عند أول تشغيل يُنشأ ملف قاعدة البيانات تلقائيًا نظيفًا (بدون أي بيانات تجريبية).
>
> **لترقية قاعدة قديمة** (حذف القيود المكررة وترقية بنية قاعدة قديمة): شغّل `upgrade.py` من الطرفية قبل فتح النظام.

### ⚙️ الأجهزة على نفس الشبكة (Wi-Fi واحد)
- افتح `http://IP-جهازك:5010` من أي جهاز (اكتب `ipconfig` لعرض الـ IP).
- النظام مرتبط بـ `0.0.0.0` تلقائيًا، وجدار الحماية ينبغي أن يسمح بالمنفذ 5010.

### 🌍 الوصول من أي مكان (استضافة سحابية)
اتبع دليل `docs/الاستضافة.md` — الاستضافة على منصة مجانية بعيدة عن جهازك تتيح الفتح من أي جهاز في العالم.

## 🧰 بنية المشروع
```
app.py           تطبيق الويب (Flask)
database.py      قاعدة البيانات (SQLite) + النسخ الاحتياطي + ترقية/تنظيف تلقائي
upgrade.py       ترقية قاعدة قديمة (حذف المكرر + ترقية البنية)
excel_tools.py   تقارير Excel الفخمة
pdf_tools.py     تقارير PDF العربية الفخمة
wsgi.py          نقطة دخول الاستضافة
templates/       صفحات النظام (RTL عربي)
static/          التنسيقات والجافاسكربت
fonts/           خط Noto Sans Arabic لتقارير PDF (بدون مربعات)
instance/        تُنشأ تلقائيًا (قاعدة البيانات)
```
